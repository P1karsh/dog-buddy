# Dog Buddy 🐾

A Chrome extension that puts a tiny dog on your web pages. Pick a **Golden Retriever**, a **Bernese Mountain Dog** (bigger and fluffier) or a **Labrador** (yellow, black or chocolate), give them a name, and choose what they do:

- **Cheer me on**: sits on your page, does tricks (twirls, hops, play bows, big smiles) and cheers you up now and then.
- **Nap**: sleeps on top of your page. Click to get a sleepy wag.
- **No-scroll patrol** (works with either): when you open YouTube Shorts, Instagram Reels, TikTok or any site you add, the dog wobbles over to a ✕ and boops the tab closed. You can allow some **grace time** per day first.
- **Auto-sleep**: naps when you step away from the computer and greets you when you're back.

Drag the dog anywhere (he remembers the spot across tabs) and click to pet. The toolbar icon opens the side panel, which shows how many tabs he's booped today.

## Install (developer mode)

1. Open `chrome://extensions` (or `edge://extensions`, `brave://extensions`).
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and pick this folder.
4. Pin the paw icon to the toolbar and click it to open the side panel.

After editing code, press the reload ↻ button on the extension card, then refresh open tabs.

## Project layout

```
manifest.json        Extension config (Manifest V3)
background.js        Service worker: side panel, closing booped tabs, boop counter, idle detection
content/dog.js       Runs on every page: draws the dog, drag/pet, tricks, patrol + grace timer
shared/dogs.js       The three dog "rigs" (SVG parts + poses + animations)
shared/settings.js   Settings defaults, site matching, daily counters
panel/               Side panel UI
icons/               Toolbar icons (generated by tools/make-icons.mjs)
dev/                 Dev-only pages, not used by the extension
```

## Dev pages

Start any static server in this folder (for example `python -m http.server 5178`) and open:

- `dev/gallery.html` shows every breed in every pose, with buttons for each trick.
- `dev/playground.html` runs the real content script and side panel with a fake `chrome` API, so you can test dragging, the Shorts boop, grace time and auto-sleep without installing.

## Notes

- Chrome doesn't let extensions draw on the tab strip or address bar, so the dog lives inside the page. He can't appear on `chrome://` pages, the New Tab page or the Chrome Web Store.
- Short-form detection: YouTube `/shorts/…`, Instagram `/reel/…` and `/reels/…`, all of TikTok, and any custom sites. A custom entry like `facebook.com/reel` only matches that path; `reddit.com` covers the whole site including subdomains.
- Grace time is shared across all patrolled sites, only counts while the tab is visible, and resets at midnight.
